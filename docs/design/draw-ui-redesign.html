设计要点

这版不是只换皮，而是把“生成”变成更顺手的创作流程。

提示词分层 主输入框只负责描述主体，风格、比例、张数、种子拆成独立控件，降低输入成本。
结果可操作 每张图都能放大、下载、重新生成，保留创作链路，避免“生成完就没了”。
历史可追溯 最近生成按时间倒序展示，方便对比同一提示词在不同参数下的结果。
