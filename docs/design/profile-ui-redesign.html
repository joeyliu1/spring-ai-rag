设计要点

个人中心要让用户知道“我是谁、我能做什么、账号是否安全”。

首屏信息化 把头像、姓名、角色、状态、资料摘要直接展示，不再依赖右上角头像菜单。
操作前置 编辑资料、修改密码、退出登录作为首屏按钮，减少隐藏入口造成的迷路感。
快捷回流 从个人中心直接进入知识库、AI 问答、AI 绘画，让页面不是死胡同。
